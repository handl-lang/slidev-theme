# Reference

## Public API

| item | what it is |
|---|---|
| `theme: handl` | the frontmatter switch that selects this theme |
| layouts | named layouts usable as `layout: <name>` |
| styles | oklch green ramp, square corners, `>>>` prompt motif |
| fonts | Source Sans 3 (text), Source Code Pro (code) |

## Crate

| crate | role |
|---|---|
| `slidev-theme-handl` | Slidev theme |

## Build and test

```bash
cargo build     # sibling [patch] tables resolve deps from ../<repo>
cargo test      # slidev build (see package.json scripts)
```

Dependencies are git deps on `branch = "main"`; locally the `[patch]` tables
point at sibling checkouts (regenerated by `host/scripts/dev-link.sh`).
